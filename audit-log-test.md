# Audit Log Test Plan

## Actions that need audit logging:

### Access Request Workflow
1. ✅ GRANT_ACCESS - When approving access request (already implemented)
2. ❓ REJECT_ACCESS - When rejecting access request
3. ❓ CREATE_ACCESS_REQUEST - When user creates access request
4. ❓ REVOKE_ACCESS - When access is manually revoked

### Employee Management
5. ❓ CREATE_EMPLOYEE - When new employee added
6. ❓ UPDATE_EMPLOYEE - When employee updated
7. ❓ DELETE_EMPLOYEE - When employee deleted

### Resource Management
8. ❓ CREATE_RESOURCE - When new resource added (DB, SaaS, etc.)
9. ❓ UPDATE_RESOURCE - When resource updated
10. ❓ DELETE_RESOURCE - When resource deleted

### Department/Company Management
11. ❓ CREATE_DEPARTMENT
12. ❓ UPDATE_DEPARTMENT
13. ❓ CREATE_COMPANY
14. ❓ UPDATE_COMPANY

### Authentication
15. ❓ LOGIN - User login
16. ❓ LOGOUT - User logout
